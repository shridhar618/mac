# Web Development Coursework (HTML, CSS, JavaScript, React)

Practice files from my web technologies course, covering HTML and CSS through modern JavaScript and an introduction to React.

## Contents

| Folder | Topics |
|---|---|
| `Unit1/` | HTML basics (text formatting, tables, forms, images, special characters), CSS (inline, internal, external, selectors, pseudo-classes) and a sample resume page |
| `Unit1/javascript/` | JavaScript fundamentals: DOM access, events and event handling, form validation, functions, arrays (including multidimensional), objects, dates, positioning |
| `Unit2/` | ES6 modules and features, Babel and CDN setup, and an introductory React app (`unit2-react/`) |
| Root | ES6 classes, arrow functions and Promise examples |

## Running

Open any `.html` file in a browser. For the React app:

```bash
cd Unit2/unit2-react
npm install
npm start
```
